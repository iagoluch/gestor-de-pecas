Este manual explica, tela por tela, tudo o que você vê no sistema de apontamento do posto.

## Como achar o que você procura

- Use a **busca** à esquerda para achar uma palavra (ex.: "parada", "refugo").
- O botão **?** no topo de cada tela abre este manual, em outra aba, direto no assunto daquela tela.
- Use **Imprimir este tópico** para levar a página no papel.

## Palavras que aparecem o tempo todo

| Palavra | O que é |
|---|---|
| OP | Ordem de Produção: o pedido para fabricar uma quantidade de uma peça. |
| Operação (ou etapa) | Cada passo do roteiro da peça (ex.: cortar, dobrar, soldar). |
| Roteiro | A lista de operações da OP, na ordem em que acontecem. |
| Posto, máquina ou estação | O lugar onde você trabalha e registra a produção. |
| Recurso | O nome cadastrado da máquina ou estação. |
| Apontar | Registrar no sistema o que você está fazendo ou fez. |

Mais palavras em [Glossário](topico:92-glossario).

## Se algo não bater com este manual

O sistema é a verdade. Se a tela mostrar algo diferente do que está escrito aqui, avise a liderança. Quando este manual disser "confirmar com a liderança", é porque a regra depende de uma configuração da sua fábrica que a tela não mostra.
