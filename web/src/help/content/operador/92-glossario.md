| Palavra | Significado |
|---|---|
| Apontar | Registrar no sistema o que foi feito. |
| Atividade sem OP | Trabalho que não pertence a nenhuma OP (ex.: limpeza). |
| Chapa | Folha de material cortada no Corte. |
| Cota | Uma medida da peça a conferir. |
| Crachá | Seu número de identificação, usado para confirmar quem fez ou autorizou. |
| Destaque | Separar as peças da chapa depois do corte. |
| Etapa / Operação | Um passo do roteiro. |
| Fila de Ordem | OPs esperando a vez no posto. |
| Nesting | Cada repetição da mesma chapa. |
| OP | Ordem de Produção. |
| Parada | Tempo em que o posto não produz. |
| Plano | Uma chapa com as OPs que serão cortadas nela. |
| Primeira peça | Primeira unidade após o setup, conferida antes de liberar o lote. |
| Recurso | Nome cadastrado da máquina ou estação. |
| Refugo | Peça perdida, sem conserto. |
| RNC | Relatório de Não Conformidade. |
| Retrabalho | Conserto de peças com defeito. |
| Roteiro | Lista das operações da OP. |
| Saldo | O que ainda falta produzir da OP. |
| Setup | Preparação da máquina. |
| Tarefa | Trabalho de corte programado. |
| TOTVS (Protheus) | Sistema de gestão da empresa (ERP) onde as OPs nascem. |
