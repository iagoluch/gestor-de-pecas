Palavras que aparecem em várias telas, em ordem alfabética.

| Termo | O que significa |
|---|---|
| **A esclarecer** | Tempo em que o recurso aparece em estados que não combinam entre si no mesmo instante. Não entra no total. Precisa de conferência. |
| **Andon** | Painel feito para TV que mostra, por recurso, se está produzindo, parado, sem demanda ou fora de turno. |
| **AE (eficiência do ativo)** | Quanto do tempo disponível virou resultado: (tempo padrão das peças boas + apoio) ÷ tempo disponível × 100. |
| **Apoio** | Setup + retrabalho + atividade sem OP. Conta no cálculo de Performance. |
| **Atividade sem OP** | O recurso trabalhou, mas sem uma ordem de produção ligada. |
| **Disponibilidade** | Tempo trabalhado ÷ tempo disponível × 100. Veja a conta em [Visão Geral](topico:10-visao-geral). |
| **FTT (First Time Through, qualidade de primeira)** | Peças boas ÷ (boas + refugo + retrabalho) × 100. Peça que foi para retrabalho não conta como boa de primeira, mesmo recuperada. |
| **Fora do turno** | Horário em que a fábrica não trabalha, pelo calendário de turnos. Não entra no total de horas. |
| **H1 / H2** | Horas extras antes (H1) e depois (H2) do expediente oficial. Veja [Turnos](topico:17-turnos). |
| **KPI** | Indicador de desempenho (OEE, Disponibilidade etc.). |
| **OEE** | Eficiência geral do equipamento: Disponibilidade × Performance × FTT. |
| **OP** | Ordem de produção. |
| **Parada não planejada** | Máquina parada por motivo fora do combinado (falta de material, quebra). Conta contra a Disponibilidade. |
| **Parada planejada** | Parada prevista (pausa de almoço, por exemplo). Fica fora do total. |
| **Performance** | (tempo padrão das peças boas + apoio) ÷ tempo trabalhado × 100. |
| **pp (ponto percentual)** | Diferença entre dois percentuais. De 80% para 85% são +5 pp. |
| **Posto / recurso** | A máquina ou estação onde alguém aponta o trabalho. |
| **Produtividade** | Tempo em Produção ÷ tempo operacional. |
| **Protheus** | O sistema ERP da empresa. O MES lê OPs e tempos padrão dele. |
| **Recurso sem demanda** | Recurso ligado, mas sem trabalho para fazer. |
| **Refugo** | Peça descartada. |
| **Retrabalho** | Peça que volta para ser refeita ou consertada. |
| **Setup** | Preparação da máquina entre um trabalho e outro. |
| **SigmaNEST** | Programa de encaixe de peças nas chapas (corte). |
| **Tempo padrão** | Tempo esperado por peça, cadastrado no Protheus ou informado manualmente. |
| **Turno** | Janela de horário em que a fábrica trabalha. |
| **Utilização** | Tempo trabalhado ÷ tempo operacional. Hoje dá o mesmo número que a Disponibilidade. |

## Estados de dado

Alguns cartões mostram, no lugar do número, uma frase de estado:

| Estado | Frase mostrada |
|---|---|
| Disponível | (o número normal) |
| Parcial | "Dados parciais disponíveis para o período." |
| Dados insuficientes | "Ainda não há dados suficientes para este indicador." |
| Sem registros | "Nenhum registro encontrado para o período." |
| Inconsistente | "Os registros do período estão inconsistentes e precisam de conferência." |
| Não configurado, Não aplicável, Não identificado | Aparecem com esses nomes. |
